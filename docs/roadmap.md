# MeshChat Roadmap (baseline)

This roadmap summarizes the planned incremental phases to evolve DisasterConnect
into MeshChat. This file mirrors the project roadmap provided to the engineering
agent and will be expanded in future phases.

Primary focus for initial phases:

1. Phase 0 — Baseline and architecture audit (this phase)
2. Phase 1 — Message protocol (versioned envelope, validation, tests)
3. Phase 2 — Transport abstraction (pluggable transports, UDP implementation)
4. Phase 3 — Peer discovery (PeerManager)

Refer to the full project plan in the repository root for more details.
